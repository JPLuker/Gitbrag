# Gitbrag maintenance audit

Audit date: 2026-10-22. Candidate: 0.9.10. Tracking: [release issue #1](https://github.com/JPLuker/Gitbrag/issues/1).

**Status: preparation complete; 1.0 acceptance is still pending.**
No visual redesign is in scope. AGENTS.md records Joseph's project-specific
exceptions. FINAL-TEST.md remains the real-browser gate; unchecked means
unverified, not automatically broken or automatically passed.

## Completed in source

- Added support and license-status documentation, a network/storage disclosure,
  bug/feature templates, private-security reporting guidance, and changelog.
- Added report/security links using the existing footer and popup structure.
- Bundled Inter with its upstream SIL Open Font License notice. Removed
  Google Fonts/preconnect requests while retaining the font family.
- Added a website Content Security Policy and no-referrer policy. Inline styles
  remain necessary for generated calendars, colors and layout; scripts are local.
- Confirmed source uses escaped public strings/safe GitHub links in repository
  renderers. Generated embed helper checks both message origin and source.
  Outbound embed messages contain height only; wildcard delivery is intentional
  because hosts may be on any origin. This is a source review, not a penetration test.
- Kept extension permissions at storage plus its two public-data API hosts.
- Added VERSION and synchronization/check scripts for website/cache/popup/manifest
  versions, dependency-free verification, pinned-action CI, weekly Actions
  dependency updates, and tagged-CI ZIP/checksum preparation into a draft release.
- Ran the four existing test suites and all root/extension JS syntax checks.
  New verification also checks version consistency and bundled HTML assets.

## Maintenance after acceptance

No planned feature development. Check issues weekly and acknowledge new issues
within 7 days. Security reports take priority. Fix ordinary bugs in patch
releases and keep compatibility with GitHub navigation/API changes. Keep
security updates enabled. If retired, say so clearly and archive the repository.
