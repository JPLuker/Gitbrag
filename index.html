SEE THE WORK AT A GLANCE

A profile built around activity.

Gitbrag pulls the useful parts of a public GitHub profile into one focused dashboard: contribution volume, active days, best days, streaks, account context, and recent repositories.

Switch instantly between 24H, 7D, 1M, 6M, 1Y, and all-time views.
Keep contribution-service failures visibly unavailable instead of turning them into fake zeroes.
Rank original public repositories without forks distorting the view.

PUBLIC DATA, CLEAR BOUNDARIES

Useful stats without another account.

Gitbrag is built around public GitHub information. The main web app is static, and unavailable contribution data is shown as unavailable instead of being silently replaced with misleading values.
