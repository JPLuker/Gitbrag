# Security

## Supported versions

The latest published version is supported. Gitbrag is preparing for 1.0;
it must not be described as stable until the release checklist is complete.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/JPLuker/Gitbrag/security/advisories/new).
Do not include vulnerabilities, credentials, or private data in public issues.
Acknowledgement is expected within 7 days. If GitHub says private reporting
is unavailable, do not post sensitive details publicly; the repository owner
must enable private reporting before the stable release.

Ordinary bugs belong in [Issues](https://github.com/JPLuker/Gitbrag/issues/new/choose).

## Scope

Gitbrag reads public profile data without GitHub tokens. It has no account
backend, telemetry, or private repository access. Report injection, unsafe
links, extension privilege abuse, or embed-message handling problems privately.
